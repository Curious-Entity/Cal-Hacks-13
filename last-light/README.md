# Last Light

A playable 2D story prototype for Cal Hacks 13. Two strangers, one night train, and choices that are remembered later.

## Run it

From the **Cal-Hacks-13 repository root**, run:

```sh
python3 -m http.server 8000 --directory last-light/dist
```

Open **http://localhost:8000**. Stop the server with **Ctrl+C**. No npm install or API key is needed. Serve the files over HTTP; browser JavaScript modules will not work by double-clicking index.html.

## Where to start if you know HTML and CSS

- **`dist/index.html`**: the layout, labels, dialogs, and clickable characters/objects.
- **`dist/styles.css`**: all styling. The color variables at the top change the whole theme. The mobile styles are near the bottom.
- **`dist/carriage.svg`**: the train illustration. It is editable vector markup.
- **`dist/story.js`**: dialogue, choice labels, characters, and the story rules. Start by editing quoted dialogue in `getView()` and labels in `getChoices()`. Keep action IDs unchanged when editing copy.
- **`dist/app.js`**: connects button clicks to the rules and updates the screen. You can customize HTML and CSS without changing this file. Keep the HTML `id` and `data-inspect` attributes so the controls stay connected.

HTML supplies the elements. CSS controls their appearance. JavaScript listens for clicks, updates the saved story state, and fills those elements with the next scene.

## What works

- Three story chapters, two characters, photograph and radio interactions.
- Twelve main decision paths leading to three endings.
- Character trust, remembered decisions, contextual dialogue, and a journal.
- Progress saved in this browser; restart asks before replacing your journey.
- Responsive layout, keyboard-accessible controls, reduced-motion support.
- Optional locally synthesized train ambience, initially muted.

## Scripted prototype and the next AI step

The current dialogue is authored, **not generated by AI**. There are no model calls, accounts, or backend secrets. This gives the team a complete playable baseline while building the AI director.

For the next iteration, add a server endpoint accepting the current game and an available action ID. Keep `takeAction()` as the authority for legal actions and state transitions. The server can give Gemini the resulting state, current story beat, and permitted next events to generate short dialogue. Validate the response; use `getView()` as the fallback when generation fails. Keep any model key on the server, never in these browser files.

Memory currently uses explicit events and relationship values. If adding private NPC conversations, track which facts each NPC knows before including those facts in its prompt.

## Verify the rules

With Node.js installed, run `npm test` from `last-light`. Tests traverse all twelve main paths and check save replay, illegal actions, the radio memory, and broken promises.

For manual QA: play a trusted-ally ending, reload mid-story, inspect the radio twice, try the secretive path, try breaking a promise, and check the layout on a narrow screen.

The `.openai/hosting.json` file identifies the private Sites demo. Source files also remain here in your GitHub checkout; this prototype does not push changes to your GitHub remote automatically.
